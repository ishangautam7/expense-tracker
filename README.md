# Expense Tracker

A simple web app to track your daily expenses. Add, categorize, and delete expenses — all in your browser.

## Installation

1. Clone the repo:
   ```bash
   git clone https://github.com/your-username/expense-tracker.git
   ```
2. Open `index.html` in your browser.

## Usage

1. Enter an **amount**, pick a **category**, and add an optional **description**.
2. Click **Submit** to add the expense to the table.
3. Click **Delete** to remove an expense.

## Tech Stack

- HTML
- CSS
- JavaScript (Vanilla)
